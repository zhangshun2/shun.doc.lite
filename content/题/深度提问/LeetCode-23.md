# LeetCode-23 合并 K 个升序链表（深度提问）

## 我现在应该能回答
- 为什么“最小堆（优先队列）”能做到每次拿到全局最小节点
- 复杂度为什么是 O(N log k)（N 是总节点数，k 是链表条数）
- 为什么把“弹出的节点的 next”再放回堆里

## 我还可以深入问
- 分治合并（两两合并）和最小堆，什么时候哪个更快
- 如果 lists 很大但多数为空，初始化堆怎么处理更省
- 如果节点值范围很小，能不能用桶/计数来加速

## 易错点清单
- lists 可能是空数组，或者里面全是 null
- 合并时要复用节点就要注意尾部 next 指针连接正确
- 优先队列比较器写错会导致顺序错误
