# LeetCode-20 有效的括号（深度提问）

## 我现在应该能回答
- 为什么“栈”适合处理括号匹配
- 为什么遇到右括号时要立即判断能不能匹配
- 为什么最后栈必须为空才算有效

## 我还可以深入问
- 如果括号种类更多（比如加入 <>），代码怎么扩展更干净
- 只给一种括号 `(` 和 `)` 的时候，能不能不用栈
- 如果字符串很长，怎么尽量减少 HashMap 的开销

## 易错点清单
- 遇到右括号但栈空：必须直接返回 false
- 最后栈不空：也要返回 false
- 用 `Stack` 还是 `Deque`：力扣里一般更推荐 `Deque`
