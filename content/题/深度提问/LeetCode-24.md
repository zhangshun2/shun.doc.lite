# LeetCode-24 两两交换链表中的节点（深度提问）

## 我现在应该能回答
- 为什么 dummy 节点能统一处理“头节点被交换”的情况
- 一次交换需要改哪几条 next 指针
- 交换完以后，循环指针应该走到哪里

## 我还可以深入问
- 递归写法怎么写，空间复杂度会变成多少
- 如果要求“三个一组旋转”或“相邻 k 个交换”，思路怎么扩展
- 如何在纸上画出指针变化，减少写错概率

## 易错点清单
- 循环条件是 `prev.next != null && prev.next.next != null`
- 交换后 `prev` 应该移动到交换后的“尾巴”（原来的 first）
- 最后剩 0 或 1 个节点必须原样保留
